# Nunito

Quick Chat embeds Nunito Regular (400), Medium (500), and SemiBold (600); it does not depend on an installed Nunito font.

Source: [googlefonts/nunito](https://github.com/googlefonts/nunito/tree/8c6a9bb9732545b9ed53f29ec5e1ab0ff53c4e6f), `fonts/variable/Nunito[wght].ttf`.
Copyright 2014 The Nunito Project Authors. Distributed under the SIL Open Font License 1.1; see [OFL-Nunito.txt](OFL-Nunito.txt).

The three static instances were generated with FontTools `fonttools varLib.instancer` using `wght=400`, `wght=500`, and `wght=600`, `--update-name-table --no-recalc-timestamp`. No glyph outlines were redesigned. Nunito's license declares no Reserved Font Names.

Chinese falls back to Microsoft YaHei UI, PingFang SC, Noto Sans CJK SC, then the platform sans-serif font.
