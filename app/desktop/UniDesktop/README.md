# UniDesktop 接入

固定使用 [UniDesktop SDK v0.2.0](https://github.com/UniDesktop/SDK/releases/tag/v0.2.0)，按 MIT 许可证分发。原生库不提交到 Git。

在 `app/desktop` 运行 `node scripts/prepare-unidesktop.mjs linux-x64`（Windows 使用 `win-x64`），再执行普通 `dotnet build`。脚本使用 curl 和 tar；在非 Windows 主机准备 Windows 库时还需要 unzip。下载归档与解压后的原生库均校验固定 SHA-256。现有发布脚本自动执行准备步骤，直接 `dotnet publish` 缺少受支持平台的库时明确失败。

`IPlatformServices.DesktopIntegration` 提供以下六组 C ABI 能力。调用包含同步桌面 IPC，应在后台线程执行；错误映射为中文异常，原生字符串用 `uda_free_string` 释放。仅从应用目录加载库，不搜索系统目录。`IsAvailable` 表示库及所需符号可加载，不保证当前会话或 D-Bus 服务支持每个操作。

| SDK 能力 | 接入与现有功能 |
| --- | --- |
| 外观 | 系统主题与 RGBA 强调色读取；Windows 情绪强调色备份改用 SDK，删除旧注册表读取。没有原值时不修改系统颜色。强调色写入/还原仍由现有实现完成，因为 SDK 不提供写入。应用继续固定深色主题。 |
| 壁纸 | 路径读取与四种填充模式设置接口，拒绝非法模式和含空字符路径。当前没有壁纸 UI 或模型工具，不额外增加入口。 |
| 通知 | Linux 待决授权使用只读提醒；Windows 保留支持审批回调和撤销的原生 toast。 |
| 常亮锁 | Display/System 两类锁，IDisposable 句柄保证只释放一次。Windows 必须在同一线程获取/释放，且同一线程不可叠加锁；不能跨 await 持有。当前没有持续常亮需求，不自动改变睡眠行为。 |
| 媒体 | 播放状态、标题/歌手/专辑/时长/进度读取，以及播放、暂停、切换、下一首、上一首、停止。无播放器返回 null/Unknown；不自动控制用户播放器。Nori 自身语音仍走现有原生音频设备。 |
| 会话与电源 | 能力位读取、锁屏、注销、挂起、休眠、重启、关机；操作先查对应能力位，除锁屏外必须传入用户显式确认。没有新增模型工具或自动调用。 |
| 托盘 | 保留 Avalonia。Nori 使用左键点击、动态菜单标题、按登录态显示/隐藏菜单项和情绪图标；v0.2.0 C ABI 缺少左键点击与已有菜单项的更新/可见性接口，直接替换会退化。 |

Linux 待决授权通过 SDK 发送只读提醒，参数不进入通知，审批仍在主界面完成。C ABI 没有通知撤销与动作回调，通知可能在审批结束后仍显示，正文明确要求以应用内状态为准。Windows 保留现有 COM toast 审批与撤销实现。应用固定深色主题，不因 SDK 系统主题读取而修改配色。

CI 在构建/测试前准备原生库，真实 C# ABI 烟测读取主题与会话能力，不修改桌面状态。发布还会校验库的 SHA-256、库与 MIT 许可证是否随包分发，并将 SDK 写入第三方清单/SBOM。缺少库或被篡改时阻止受支持平台的发布。macOS/Linux arm64 没有上游产物，不要求该库。

上游 v0.2.0 仅提供 Windows x64 与 Linux x64 产物；macOS、Linux arm64 或开发环境缺少原生库时降级为不可用，保留已有窗口与平台功能。全局光标、拖动、点击穿透尚未被上游实现，继续使用现有平台服务。SDK 不新增模型可调用工具。
