# Avalonia 原生记忆界面功能对照

本清单以提交 `381d197` 中 `app/desktop/src/components/settings/MemorySettings.vue` 的完整脚本与模板、`src/services/i18n/locales/zh-CN.ts`、`en-US.ts`、`useLanguages.ts` 的记忆文案以及 `tests/settings/memory.test.ts` 为迁移基线。旧 Vue 组件及其专属测试已由原生实现和测试替代，历史文件仍可从该提交查看。勾选表示已通过源码对照确认存在对应实现，不代表自动测试或可视验收通过；实现、自动测试与可视检查分别记录证据。

目标是独立原生 `MemoryWindow`，完整覆盖八个分区，复用设置界面的原生控件风格。根据最新要求，设置与记忆窗口统一固定深色模式，不跟随系统切换；记忆界面使用与设置一致的品牌区、图标分组导航、页面说明和分组表单。可以调整布局与控件形式，但不能用原始 JSON 替代结构化信息、丢失操作或把失败显示成成功。

## 1. 通用窗口与数据行为

- [x] 主界面记忆入口打开独立原生窗口；八区分别为概览、长期记忆、记忆原子、ARG / Memory.md、归档、记忆迁移、检索调试、高级设置；初始为概览。
- [x] 系统窗口标题为“长期记忆库管理”；品牌区使用简洁的“记忆”，内容区按分区呈现标题与专属说明，避免重复标题；窗口和详情、确认弹窗均使用深色主题。
- [x] 长内容、路径、标签与来源消息配置换行和滚动；窗口最小720×480，详情与确认窗口受父窗口可用尺寸约束。66张记忆截图的生成及其验收范围见末节。
- [x] 通过后台宿主服务获取数据，提供加载、空态、错误、重试与操作禁重入；列表、详情、调试和迁移使用请求版本/取消保护旧结果。此项记录防护实现，不代表全部并发排列均已实测。
- [x] 保存、新增、归档、恢复、删除、清空、导入完成后更新列表及概览快照；失败保留可修正的输入，并显示对应中文错误。
- [x] 本地日期时间可读；无效时间不崩溃；来源 agent/manual 显示“AI 自动记忆”/“手动记录”，未知来源保留可辨识信息。
- [x] 状态 active/dormant/expired/archived 显示“活跃/休眠/已过期/已归档”；expired 或到期时间早于当前时间均显示已过期。
- [x] 新界面不额外记录记忆正文、查询、来源消息或迁移文件内容到日志/遥测；原生来源使用独立身份与命令白名单，不冒充 main 或 settings。
- [x] 普通关闭先处理草稿/在途操作再隐藏；隐藏保留页面和筛选输入、暂停刷新并失效旧请求，重开刷新。应用退出销毁时取消任务、退订通知并释放服务；安全模式拒绝联网能力但保留本地管理。

## 2. 概览

- [x] 四张统计卡显示活跃记忆、活跃原子、已归档、知识块；展示索引 state 以及 processed / total。
- [x] 四个开关分别修改 enabled、reflectionEnabled、decayEnabled、archiveEnabled，并显示“已启用/已停用”。
- [x] 修改失败显示“保存记忆失败”；保存后从真实快照刷新，不展示虚假成功状态。

- [x] 类型全量覆盖 general/factual/preference/relational/planned/identity，对应通用/事实/偏好/关系/计划/身份；默认 general。
- [x] 新增重要度默认0.8，范围0.1–1.0、步长0.1并展示百分比；成功关闭新增编辑器，下次新建为默认空表单；失败保留当前草稿。
- [x] 列表标题含总条数；支持手动重载、清空所有记忆；清空是全部个人长期记忆，不能误解释成当前筛选结果。
- [x] 搜索含清空按钮；300ms 防抖；正文、规范摘要、Nori 视角摘要及标签均可匹配；筛选改变回到第一页。
- [x] 类型筛选含“全部类型”与六种类型；状态筛选含“全部状态”、活跃、休眠、已过期。
- [x] 每页20条，按更新时间降序；显示当前页/总页数、上一页/下一页及正确的边界禁用；删除最后一页条目后不滞留无效页码。
- [x] 每条显示标签（非空时）、来源、类型、重要度百分比、状态、额外到期提示、正文、创建时间及可选最近访问时间。
- [x] 原生条目通过明确的“记忆详情”按钮打开详情；归档/恢复/删除均为独立按钮，不触发详情；已归档条目提供恢复，其他条目提供归档。
- [x] 无记录、搜索无匹配、加载失败三种状态有不同文本；失败有“重新加载”入口；新增失败显示“添加记忆失败”。

## 4. 详情、编辑与确认

- [x] 详情标题包含记忆编号，加载期间显示状态；详情为原生所有者模态窗口，不使用可点击关闭的Web遮罩。
- [x] 可编辑正文、规范摘要、Nori 视角摘要、类型、标签、置信度与重要度；两种摘要缺失时以正文初始化；置信度/重要度缺失时默认0.8。
- [x] 置信度与重要度范围0–1、步长0.05，可精确输入并显示百分比；保存仅在内容非空且有修改时启用。
- [x] 顶部展示状态、类型、来源；有效期展示已过期、具体到期时间或永久有效。
- [x] 来源对话显示总数、每条 role、sequence 编号、可选 messageTime、保留换行的 content；无来源显示“暂无关联来源对话”。
- [x] 生命周期展示创建、更新、最近访问、最近强化四种时间；缺少后两项时分别显示“暂无访问记录”“暂无强化记录”。
- [x] 展示访问次数/强化次数、存活天数 TTL；缺失计数回退0，缺失 TTL 显示占位。
- [x] “事实原子与底层溯源”可折叠，初始收起，并显示原子总数；有 supersededBy 时显示替代记忆编号。
- [x] 每个关联原子显示 atomType、importance/confidence百分比、status、id、content、可选 decayType 与 entities；无原子显示“暂无事实原子”。
- [x] 详情含保存、取消、归档或恢复、删除；保存成功重新读取详情与列表，失败显示“保存记忆失败”并保留编辑。
- [x] 未保存详情关闭/取消时提供“继续编辑”和“放弃修改”；继续编辑保留全部字段。原生模态窗口阻止用户直接操作后方分区；宿主关闭流程同样处理未保存草稿。
- [x] 归档确认明确“归档后将不再参与日常检索”；恢复确认明确“重新进入活跃记忆池”；取消不得调用业务命令。
- [x] 删除单条与清空全部各有确认，清空明确“此操作不可恢复”；命令分别携带 DELETE_MEMORY / CLEAR_PERSONAL_MEMORY 确认令牌。
- [x] 归档、恢复、删除成功关闭当前目标详情并刷新；false 返回视为失败，异常显示可读错误。保存错误同时保留局部提示和底栏失败状态，不由公共操作封装误报完成。

## 7. 记忆迁移

- [x] 导出说明包含只导出记忆文本、摘要、标签等白名单，不包含原始向量、来源聊天正文、工具参数；不要暗示正文中的所有个人信息已自动匿名化。
- [x] “导出脱敏记忆”展示执行状态并禁止重复；成功显示总计/活跃/归档数量、实际 sanitizedFields 清单、“隐私保护”标识与安全说明。
- [x] 生成成功后可通过原生保存对话框保存返回的原始 JSON content、复制相同内容；保留服务端文件名，复制成功有反馈；取消保存不报告文件已保存。
- [x] 导出失败显示错误条和重试；保存或复制失败显示“导出记忆失败”，不得回退成与真实格式不同的摘要 JSON。
- [x] 导入提供选择/更换 JSON 文件、文件名、格式和大小限制、实际文件大小；仅承诺已实现的选择方式（Vue文案说拖拽但模板未实现 drop 事件）。
- [x] 非 .json、超出大小、读文件失败、非法 JSON、结构/版本错误都有明确错误；替换文件前清除旧预览，取消选择不提交数据。
- [x] 原生以核心4 MiB UTF-8边界为准，而不是复刻Vue的5 MiB初筛；读取须有实际流大小限制，不能只信文件元数据。
- [x] “解析并预览”仅在有有效读取内容时可用；解析中禁重入，失败显示服务端可读错误；预览不写库。
- [x] 预览显示待导入总数、新增、重复、冲突统计；列表展示条目数、受限摘要、类型、重要度、可选标签、冲突类别/原因；无有效条目有空态。
- [x] 展示隐私说明：预览仅含受限摘要和核心元数据，不包含原始向量与来源对话正文。
- [x] 冲突策略包含 skip（默认）、overwrite、create_copy，对应跳过、覆盖、保留并新建；预览提交只发送服务端令牌与策略。
- [x] “取消并清空”清除文件内容、预览、错误及文件选择；更换文件/重新解析后不得继续使用旧令牌。
- [x] “确认并执行导入”非空且有效预览才可启用；独立“确认导入记忆数据”对话框，取消不写库，执行中禁重入。
- [x] 成功清空预览并刷新列表/快照；失败或 success=false 显示错误，不能伪造成功；令牌过期/已用时可重新解析。
- [x] 核心限制保持1000条、字段16 KiB、4 MiB总UTF-8字节、令牌5分钟且一次性；导出继续使用领域白名单，不能导出内部ID/向量/来源正文。

## 9. 高级设置

- [x] 向量索引重建说明包含更换Embedding模型或维数后重算全量向量；执行时显示计算状态，结束显示实际完成条数，失败通过公共错误区显示服务端可读原因。
- [x] 八个数值字段分别为 reflectionRounds（1–32，默认8）、reflectionMinChars（100–20000，默认2500）、recallTopK（1–20，默认6）、keywordTopK（1–100，默认20）、vectorTopK（1–100，默认20）、rrfK（1–500，默认60）、minSimilarity（0–1，默认0.25）、archiveThreshold（0–1，默认0.15）；后二者步长0.01。
- [x] 每字段独立保存/防抖，焦点编辑不被快照覆盖，失焦可立即保存；保存中/失败状态可见；校验拒绝非有限值与无效数值。
- [x] 三个开关 knowledgeEnabled、knowledgeWatch、debugRetrieval 对应知识库、知识库监听、完整检索日志，显示启停状态；原生开关统一采用400ms防抖自动保存，而非Vue的立即提交。前两项保持在高级页。
- [x] 安全模式禁止 memory_reembed_all、memory_knowledge_reindex、memory_recall_debug、memory_search_hybrid；本地开关设置、列表、详情、增删改、迁移仍可用，底层仍须执行安全模式校验。

## 10. 验证证据与尚未实测范围

实现证据为 `MemoryWindow.cs`、`MemoryWindow.Pages.cs`、`MemoryWindow.Editor.cs`、`MemoryWindow.Transfer.cs` 及原生记忆服务。上述勾选是最终源码功能对照；原生控件形式与Vue不同，但八区及详情字段、确认和数据能力均有对应实现。

已有测试分工：

- `NativeMemoryWindowTests`：窗口重开保留页面/搜索、设置与语言切换、结构化检索结果。
- `NativeMemoryEditorTests`：来源与可编辑字段、保存、丢弃确认、归档/删除确认边界。
- `NativeMemoryFieldSaveTests`：字段独立保存、在途新草稿串行化、失败后保留与重试。
- `NativeMemoryLifecycleTests`：保存期间禁用输入、失败后恢复草稿、确认窗口保持可操作以及取消后的编辑恢复。
- `NativeMemoryTransferUiTests`：实际UTF-8流大小、非法编码/JSON、三种冲突策略、预览元数据、提交失败草稿保留、本地取消清空与旧令牌失效；通过流和内部方法驱动，未自动操作真实系统文件选择器。
- `NativeMemoryHostTests`：原生来源/命令白名单、可见性、确认令牌、安全模式以及指定取消场景。
- `Nori.Core.Tests/MemoryTransferTests.cs`：核心导出白名单、UTF-8和数量限制、事务提交、冲突策略、五分钟令牌及并发一次性消费。
- `NativeMemoryVisualTests`：使用真实Avalonia/Skia渲染的headless截图，覆盖中英文、720×480、默认960×640与1920×1080；不是占位图，也不等于真实操作系统桌面人工验收。
