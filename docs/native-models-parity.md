# 原生模型窗口功能对等清单

模型管理使用独立的 Avalonia `ModelsWindow`，沿用原生设置和记忆窗口的导航、卡片、字体和 `SettingsTheme.axaml` 色源。只支持深色模式，默认 960×640，最小 720×480。

## 入口与权限

- 主窗口侧栏「模型」和主页「模型换装」调用 `RUNTIME.openModels()` → `window_open_models`；主面板与音频宿主保持运行。
- 模型窗口按需创建、重复打开复用、恢复最小化；普通关闭先保存再隐藏。
- 独立 `models` 来源只允许模型领域白名单，不冒充 `main` 或设置来源。路由入口与命令入口都检查权限。
- 沿用现有模型命令和配置存储；`model_get_meta.selectedExpressions` 返回该模型已保存的表情选择，`expressions` 仍是可用表情列表。

## Vue 功能映射与验收

| 区域 | 对等行为 |
| --- | --- |
| 模型库 | 固定 ARG Nori / Nori 两种模型，名称、缩略图、安装/启用状态、安装数量及当前角色；未安装不可启用或调整，当前角色不可重复启用 |
| 本地导入 | 单个 ZIP 或文件夹；使用既有路径校验、固定模型 ID 和替换回滚；取消不显示成功，成功显示导入 ID；导入不自动切换当前模型 |
| 调整 | 可调整任意已安装模型，不要求先启用；加载中、失败、无表情/动作状态可见 |
| 显示 | 缩放 0.5–4（步长 0.05）；表情单选、再次点击取消或选「无」；按模型保存并兼容旧全局键 |
| 渲染 | 每模型阴影、渲染倍率 0.5–4（步长 0.25，默认 2）、最大帧率不限/30/60；不新增 Vue 未提供的透明度或质量模式字段 |
| 全局行为 | 点击互动、点击穿透、AI 互动、自动眨眼、视线跟随、待机眼部动画、待机动作、表情系统、口型同步、节拍同步十个开关 |
| 能力提示 | 点击穿透受平台能力限制；AI 互动受 AI 配置和安全模式限制，并说明费用及本地回退；节拍同步说明音源要求 |
| 互动区域 | 每模型最多 32 个；默认居中半宽半高矩形；列表/舞台选择，拖动空白创建、移动、八方向缩放，边界钳制，反向拖动、指针捕获 |
| 键盘 | 舞台焦点下方向键移动 0.01，Shift 加速至 0.05；Delete/Backspace 删除所选区域，不能误删名称输入；Esc 先取消选择再退出调整，弹窗优先处理 |
| 区域表单 | 名称、local/ai 反应、动作 none/random/selected（动作组和文件名）、表情 none/random/selected；失效绑定可见；删除单个无需确认，清空全部需确认 |
| 测试模式 | 编辑/测试切换只改变舞台手势；重叠区域命中最小面积、同面积保持配置顺序；只执行本地动作与表情，即使区域设为 AI 也不联网 |

## 保存与生命周期

- 缩放、表情、渲染倍率和互动配置按模型 ID + 字段独立防抖约 400ms；行为开关、阴影、帧率和启用即时保存。
- 返回模型库、完成、关闭和退出都等待待保存内容及在途写入；失败保留编辑和可见错误，允许重试。
- 异步元数据或快照不能覆盖脏字段，也不能把旧模型结果应用到新模型。
- 隐藏暂停渲染并取消旧查询；重新显示刷新。退出调整释放预览资源；应用退出先完成写入再释放窗口。

## 预览隔离

- 独立 `PetRuntime` 与 `PetGlControl`，复用原生 SDK，不创建第二个桌宠窗口。
- 预览目标显式指定；加载失败、点按和试播不能修改全局当前模型，不能发送 AI 请求或接入音频宿主。
- SDK 生命周期与共享静态状态在多上下文之间协调；GL 创建、上传和释放必须发生在所属上下文。
- 模型文件读取、JSON 解析和纹理解码在后台完成，GL 提交只消费当前世代的内存资源；解码串行限制快速切换时的内存峰值，排队取消不执行解码。
- 无 GL 或加载无响应在 30 秒后明确失败并作废待提交资源；隐藏、关闭和新请求的正常取消不会被显示为失败。构造失败回收原生模型、渲染器及已上传纹理，清理错误不覆盖原始加载错误。
- 模型画布归一化坐标与舞台坐标共用映射，覆盖缩放、留白、系统 DPI 和渲染倍率；同 ID 重新导入后允许真正重载纹理。

## 清理边界

原生覆盖建立后移除旧模型管理/显示/行为/互动 Vue 组件及浏览器预览专用实现、Pixi 依赖和浏览器 Cubism Core 脚本。保留 `services/live2d/models.ts` 和缩略图、首次运行选择/导入、主页角色信息、共享运行时类型、原生 SDK 及 Cubism Core。Vite `base: "./"` 不变。
