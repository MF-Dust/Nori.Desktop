# 原生设置功能对照与维护边界

对照基线：Vue 设置迁移前提交 `02333f62ded9ea0997b31b1783fad6fded9b430b`。原生菜单保留原来的十一项页面，模型管理与长期记忆仍在主窗口的独立入口中。

视觉参考来自 [Nori.Web](https://github.com/MF-Dust/Nori.Web) 的 `theme-nori`、侧栏导航和 [设置玻璃样式](https://github.com/MF-Dust/Nori.Web/blob/master/public/nori-settings-glass.css)。原生控件保持系统窗口行为，以蓝灰色表面、青色强调、统一卡片和响应式表单表达同一风格。

## 状态与布局

- 运行时快照请求串行合并，仅查询当前复杂页面。原生 MCP 列表读取不再广播一次新的状态变化，避免查询反馈循环。
- 诊断页保留筛选器、日志容器与页面根；状态变化不销毁滚动条。其它复杂页面保留搜索与筛选外壳，只在对应数据变化时重建列表。
- 普通配置字段独立防抖保存，快照不覆盖未保存编辑。密码快照只更新“已配置”状态。
- 颜色仅定义在 `SettingsTheme.axaml`；普通表单、复杂页面和对话框共用资源。共享画刷在系统主题切换时就地更新。
- 小窗口中表单标签与编辑器分行，操作组允许换行；页面采用有限宽度和纵向滚动。关闭前等待保存与查询结束。

## 验证与产物

现有三平台 CI 保持源码扫描、前端检查/构建/测试、后端构建/测试和打包门禁。新增回归覆盖刷新循环、滚动与焦点、隐藏页面查询、密码状态、平台能力、更新进度、提供方参数和提醒时间协议。

Windows 的专门视觉步骤设置 `NORI_CAPTURE_SETTINGS=1`，使用生产 App 主题和真实 Skia 渲染，生成十一页、两种主题、两种窗口尺寸的截图。产物名为 `nori-native-settings-visuals`，包含 PNG、布局清单与 SHA-256。使用隔离测试数据库及合成内容，不读取个人配置。

自动化测试不代替真实第三方服务的联网验证。提供方、MCP 和插件操作继续由既有宿主命令与权限策略执行。
