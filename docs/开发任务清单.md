# Nori Desktop 当前交付清单

本文件记录仓库当前真实范围，不把历史设想当成已实现功能。`[x]` 表示代码和测试已经存在；“暂不交付”表示有意不纳入当前版本，不是 CI TODO/FIXME 门禁的例外。

## 2. 当前验收顺序

1. Windows x64 全新临时 profile 启动 `first-run`，确认 readiness 后退出。
2. Windows x64 隔离 profile 启动 `initialized`，确认 readiness 后退出。
3. 安装 ASP.NET Core Runtime 10 和 WebView2 后，运行 framework-dependent ZIP，确认前端资源、Cubism Core 和窗口可用。
4. 在本地导入 `arg-nori` 或 `nori` 模型，确认伴侣渲染、拖动、点击和设置预览。
5. 配置一个受支持的 LLM/TTS/STT 端点后验证聊天、流式输出、语音播放/录音和口型。
6. 在 Linux/macOS 上执行 CI 同等的编译、单元测试和槽式 framework-dependent 发布结构验证；平台增强能力按 [`跨平台.md`](./跨平台.md) 验证。

## 3. 明确暂不交付

以下项目不属于当前版本的隐藏 TODO，未完成时不能在 README、发布说明或验收结论中宣称已支持：

- 安装器、代码签名、自动更新、更新服务器和自包含 .NET Runtime
- macOS/Linux 安装器、签名与自动更新（当前仅提供槽式 framework-dependent 归档）
- Live2D/模型 CDN、网关签名 URL、远程模型下载、暂停/恢复下载和模型更新
- 本地大模型随包安装、内置 GPT-SoVITS Runtime 及其模型
- 版本检查、软件更新窗口和 AI 更新事件
- Android 发行版
- 额外模型的产品目录承诺；本版本只验收 `arg-nori` 与 `nori`

若要扩大上述范围，先更新架构、平台矩阵、许可清单和 CI/release 设计，再实现代码；不要用一个未执行的 `[ ]` 任务掩盖发布前提。
